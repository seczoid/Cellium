# Product

## Register

product

## Users

Cellium is for people working with large local tabular files and spreadsheet-style workbooks. They need to open, inspect, edit around, and return to work quickly without learning database internals.

## Product Purpose

Cellium is a fast local workspace launcher and spreadsheet editor for big files. The dashboard exists to open or import files, create blank workbooks, find recent work, and make it clear that work is saved locally.

## Brand Personality

Fast, precise, trustworthy. The product should feel native, dense, calm, and sharp: closer to RowZero and Raycast than a marketing dashboard.

## Anti-references

Do not look or read like a database admin console, cloud connections hub, SaaS analytics homepage, or engine-debug screen. Avoid exposing DuckDB, Arrow, materialization, data sources, connections, or query-engine jargon in the user-facing dashboard.

## Design Principles

- Fast entry: the main actions and search should be immediately available.
- Plain-language copy: describe what users can do, not how the engine works.
- Local-first trust: calmly show that files stay on this Mac.
- Hide internals: keep storage and import mechanics behind simple actions.
- Dense polish: use restrained dark UI with clear states and strong alignment.

## Accessibility & Inclusion

Target WCAG AA contrast, visible focus, keyboard-first search, readable dense layouts, and reduced-motion-friendly interactions where motion is added.
